# rust-asm-calc

Экспериментальный консольный калькулятор на
Rust. Вся математика написана через встроенный
ассемблер (`std::arch::asm!`) под архитектуру
x86_64.

Делал проект для практики в
системном программировании, работы с
регистрами
процессора и безопасной оберткой над
`unsafe`-кодом.

## Как устроено

- **Математика (`src/math.rs`):** арифметика с плавающей точкой (`f64`) через векторные инструкции SSE2 - сложение (`addsd`), вычитание (`subsd`), умножение (`mulsd`) и деление (`divsd`) на регистрах `xmm`. Функции возвращают `Result<f64, &'static str>`, чтобы программа не падала при делении на ноль.
- **Интерфейс (`src/cli.rs`):** интерактивное меню в консоли сделано на крейте `inquire`.
- **Сборка (`Cargo.toml`):** для релиза включены `lto` и `strip`, чтобы уменьшить размер итогового `.exe`.
