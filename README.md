# rust-asm-calc

Экспериментальный консольный калькулятор на
Rust. Вся математика написана через встроенный
ассемблер (`std::arch::asm!`) под архитектуру
x86_64.

Делал проект для практики в
системном программировании, работы с
регистрами
процессора и безопасной оберткой над
`unsafe`-кодом.

## Как устроено

- **Математика (`src/math.rs`):** целочисленная арифметика (`i64`) через инструкции процессора x86_64 - сложение (`add`), вычитание (`sub`), умножение (`imul`) и целочисленное деление (`cqo` + `idiv`). Функции возвращают `Result<i64, &'static str>`, чтобы программа не падала в панику при делении на ноль
- **Интерфейс (`src/main.rs`):** интерактивное меню в консоли сделано на крейте `inquire`
- **Сборка (`Cargo.toml`):** для релиза включены `lto` и `strip`, чтобы уменьшить размер итогового `.exe`
